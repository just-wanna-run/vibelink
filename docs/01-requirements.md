# 产品需求文档 (PRD)

## 产品名称
VibeLink — 网页版文件传输助手

## 产品定位
类似微信「文件传输助手」的独立网页应用——打开浏览器就能用，手机电脑互传任何内容，轻量、安全、有历史记录。

## 核心需求

| 编号 | 需求 | 说明 |
|------|------|------|
| R1 | 跨平台 | iOS Safari / Android Chrome → Windows PC 浏览器 |
| R2 | 免安装 | 纯网页，打开即用，无需下载 App |
| R3 | 账号登录 | 邮箱+密码、手机号+验证码两种方式 |
| R4 | 记住密码 | 支持 30 天免登录 |
| R5 | 同账号同步 | 登录同一账号即可收发，无需配对码 |
| R6 | 文字传输 | 实时发送文字内容 |
| R7 | 图片传输 | 支持拍照/相册/粘贴 |
| R8 | 文件传输 | 任意格式，最大 1GB |
| R9 | 端到端加密 | 所有内容在客户端加密，服务器不可见 |
| R10 | 传输记录 | 按时间线展示，支持搜索和删除 |
| R11 | 联网传输 | 走互联网，无需同一局域网 |

## 文件传输策略
- ≤10MB：服务器中转（快速送达）
- >10MB：优先 WebRTC P2P 直连
- P2P 失败时：云存储（Cloudflare R2）中转兜底

## 非功能需求
- 轻量：首屏加载 < 3 秒
- 安全：所有数据端到端加密
- 可靠：消息不丢失，断线自动重连
