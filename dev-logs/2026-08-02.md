## 技术栈最终确定

| 层面 | 选型 |
|------|------|
| 前端 | React 18 + TypeScript + Vite 5 |
| 状态管理 | Zustand |
| 样式 | 纯 CSS（淡蓝色主题 #5B9BD5） |
| 后端 | Express 4 + TypeScript |
| 数据库 | sql.js（WebAssembly SQLite，零编译） |
| 认证 | JWT（7天/30天记住密码） |
| 实时通信 | ws (WebSocket) |
| 大文件 | WebRTC P2P（64KB 分块） |
| 加密 | Web Crypto API（AES-256-GCM + PBKDF2） |
| 部署 | Vercel (前端) + Render (后端) |

## 遇到的问题及解决
1. **better-sqlite3 需要 Python 编译** → 切换 sql.js（WASM，纯JS）
2. **WebRTC P2P 信令中继** → 扩展现有 WebSocket 服务端
3. **记住密码时无法解密密钥** → AES 密钥暂存 localStorage
